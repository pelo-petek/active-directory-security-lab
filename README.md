# Active Directory Security Lab

This repository documents a self-built Active Directory offensive security lab created for educational and research purposes.

The lab focuses on common Active Directory attack techniques, credential abuse, lateral movement, and corresponding remediation recommendations.

## Techniques Covered

- Remote Command Execution via PsExec/SMB
- LLMNR Poisoning
- Kerberoasting
- DCSync
- AS-REP Roasting
- DCShadow
- PetitPotam NTLM Relay to AD CS
- Pass-the-Ticket
- Credential extraction with Mimikatz
- Lateral movement

## Tools Used

- Metasploit
- Mimikatz
- Rubeus
- Impacket
- Responder
- Hashcat
- Evil-WinRM
- PsExec
- OpenSSL

## Lab Environment

All testing was performed in an isolated virtual laboratory environment.

No real-world systems or third-party client systems were targeted.

All IP addresses, usernames, hostnames, and sensitive information shown in the report were simulated, anonymized, or redacted.
